# Guía de desarrollo del proyecto

La especificación es `ESPECIFICACION.md`; léela antes de cada fase y sigue las reglas de la sección 7.

## Comandos del proyecto

- `npm run dev`: Inicia la aplicación en modo desarrollo con recarga en vivo.
- `npm run build`: Compila los bundles de Electron (main, preload, renderer).
- `npm run typecheck`: Valida tipos TypeScript en main, preload y renderer.
- `npm run lint`: Ejecuta ESLint verificando reglas de código y restricciones de importación entre capas.
