# Explorador de archivos

El **Explorador de archivos** es la herramienta principal para navegar, organizar y gestionar todos los documentos, imágenes, música, videos y carpetas dentro de **hebi OS**.

## Características principales

- **Navegación fluida:** Acceso rápido a Inicio, Escritorio, Descargas, Documentos, Imágenes, Música, Videos y Disco local (C:).
- **Vistas personalizables:** Cambia entre vista de Íconos grandes, Lista y Detalles para consultar fecha, tipo y tamaño.
- **Barra de direcciones:** Muestra rutas legibles estilo Windows (`C:\Usuarios\<nombre>\...`) y permite navegar haciendo clic en las migas de pan.
- **Acciones de archivo:** Crear nuevas carpetas y documentos de texto, Renombrar, Duplicar, Copiar a…, Mover a… y Eliminar.
- **Importación de archivos reales:** El botón **Importar desde el equipo…** permite transferir archivos reales desde tu sistema anfitrión a la carpeta actual.
- **Papelera de reciclaje:** Vista dedicada para restaurar elementos eliminados o vaciar la papelera de forma permanente.

## Atajos y consejos

- Haz doble clic en una carpeta para abrirla o en un archivo para abrirlo con su aplicación predeterminada.
- Haz clic derecho sobre cualquier elemento para acceder a opciones avanzadas como **Abrir con…** y **Propiedades**.
- Puedes arrastrar archivos entre carpetas o directamente al Escritorio y a la Papelera de reciclaje.
