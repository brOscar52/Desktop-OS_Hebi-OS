# Contactos

La aplicación **Contactos** gestiona tu libreta de direcciones personal, organizada alfabéticamente.

## Características

- **Directorio ordenado:** Lista alfabética (A-Z) con contador y búsqueda inmediata por nombre, teléfono o correo electrónico.
- **Ficha completa:** Guarda nombre, apellido, múltiples números de teléfono clasificados (Móvil, Casa, Trabajo), correos, dirección postal, fecha de cumpleaños y notas.
- **Foto de perfil:** Asigna una foto a cualquier contacto eligiendo cualquier archivo de imagen de tu sistema de archivos virtual.
- **Gestión sencilla:** Crea, edita o elimina contactos de forma ágil y segura.
