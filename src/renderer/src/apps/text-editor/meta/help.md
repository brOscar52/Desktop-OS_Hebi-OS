# Bloc de notas

El **Bloc de notas** es un editor de texto rápido, ligero y versátil, diseñado para crear y editar notas, documentos `.txt` y archivos de Markdown `.md`.

## Funciones destacadas

- **Gestión de documentos:** Permite crear nuevos archivos, abrir documentos existentes y guardar copias con **Guardar como…**.
- **Indicador de cambios sin guardar:** Muestra un asterisco (`*`) en la barra de título cuando hay modificaciones pendientes.
- **Protección contra pérdida de datos:** Si intentas cerrar la ventana con cambios sin guardar, un diálogo te preguntará si deseas guardar, descartar o cancelar.
- **Búsqueda integrada (Ctrl+F):** Localiza palabras clave con conteo de coincidencias y botones de navegación siguiente/anterior.
- **Ajuste de línea y zoom:** Activa o desactiva el ajuste automático de línea y ajusta el tamaño del texto cómodamente.
- **Barra de estado:** Indica en tiempo real la línea y columna del cursor, el número total de caracteres y el nivel de zoom actual.

## Atajos de teclado

- `Ctrl + N`: Nuevo documento
- `Ctrl + O`: Abrir archivo…
- `Ctrl + S`: Guardar documento
- `Ctrl + Mayús + S`: Guardar como…
- `Ctrl + F`: Abrir panel de búsqueda
