# Administrador de tareas

El **Administrador de tareas** ofrece supervisión en tiempo real de los procesos en ejecución y el rendimiento de recursos en **hebi OS**.

## Páginas de monitoreo

- **Procesos:**
  - Lista detallada de todas las aplicaciones y servicios activos del sistema.
  - Columnas ordenables: Nombre de proceso, PID, porcentaje estimado de CPU y consumo de memoria RAM.
  - El botón **Finalizar tarea** permite terminar de inmediato cualquier proceso o aplicación seleccionada.
- **Rendimiento:**
  - Gráficas continuas de los últimos 60 segundos con métricas de uso de CPU y memoria física.
  - Datos del sistema simulado: velocidad del procesador, hilos activos y memoria total (16.384 MB).
