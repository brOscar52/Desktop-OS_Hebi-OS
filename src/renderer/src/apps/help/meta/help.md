# Ayuda

La aplicación de **Ayuda** es la enciclopedia oficial de **hebi OS**, creada para orientarte en tus primeros pasos y detallar las capacidades de cada una de las herramientas del sistema.

## Contenido disponible

- **Primeros pasos:** Guía fundamental sobre la sesión, el escritorio, la barra de tareas, el menú Inicio, la gestión de ventanas, el sistema de archivos y la Papelera de reciclaje.
- **Catálogo de aplicaciones:** Ficha técnica y manual de uso de las 17 aplicaciones preinstaladas en el sistema.
- **Buscador en tiempo real:** Escribe en la barra de búsqueda superior para encontrar de forma instantánea cualquier tema, atajo o aplicación.
